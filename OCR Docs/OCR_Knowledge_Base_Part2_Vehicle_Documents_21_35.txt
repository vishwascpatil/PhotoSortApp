OCR Knowledge Base - Vehicle Documents (21-35)

============================================================ 21. Vehicle
Registration Certificate (RC)
============================================================ Category:
Vehicle Registration

Required Keywords: registration certificate certificate of registration
rc vehicle registration

Optional Keywords: registration number owner name father name address
engine number chassis number vehicle class maker model fuel type color
cubic capacity seating capacity registration date registration validity
hypothecation financier rto transport department

Strong Indicators: registration certificate certificate of registration
engine number chassis number

Weak Indicators: owner name fuel type vehicle class

Negative Keywords: driving licence insurance policy pollution
certificate

Regex: Vehicle No: A-Z]{2}[0-9]{1,2}[A-Z]{1,3}[0-9]{4}ommon OCR
Mistakes: registratlon certificate englne number chassls number vehicie

Classification Notes: Presence of engine number + chassis number +
vehicle registration almost guarantees RC.
